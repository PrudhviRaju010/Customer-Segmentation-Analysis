# Customer Segmentation Analysis

## Project Overview

Developed a Customer Segmentation Analysis project to identify different customer groups based on purchasing behavior and sales patterns. 

---

## Objectives

- Analyze customer purchasing behavior
- Identify high-value customer segments
- Understand sales contribution by customer groups
- Support data-driven business decisions

---

## Features

- Customer-wise Sales Analysis
- Profit Analysis by Customer Segment
- Identification of High-Value Customers
- Interactive Data Visualizations
- Business Insights Reporting

---

## Tools Used

- Power BI
- SQL
- Excel

---

## Key Insights

- Identified top-performing customer segments
- Analyzed customer contribution to overall sales
- Compared profit trends across customer groups
- Improved customer understanding using data visualization

---

- Power BI Dashboard (.pbix)
- Dataset

- Excel Workbook (.xlsx)
